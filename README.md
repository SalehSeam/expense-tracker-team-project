# Expense Tracker

A simple and responsive personal expense tracker built with **HTML, CSS, and JavaScript**.

## Features

- Add income and expenses
- Choose transaction categories
- Automatic balance calculation
- Recent transaction list
- Delete individual transactions
- Clear all transactions
- Saves data using browser `localStorage`
- Responsive design for desktop and mobile
- No backend or database required

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage API

## How to Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start adding transactions.

## GitHub Pages

This project is ready for GitHub Pages because `index.html` is located in the repository root.

Go to:

**Settings → Pages → Deploy from a branch → main → /(root) → Save**

Your live website will be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/](https://salehseam.github.io/expense-tracker-team-project/`

## Data Privacy

Transactions are stored only in the browser's local storage. This project does not send financial information to a server.
